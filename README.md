# Vishal Varun Portfolio

A responsive personal portfolio built with React, Vite, and Tailwind CSS. It presents Vishal Varun as a frontend developer / UI engineer, with sections for selected projects, skills, background, resume download, and contact details.

## Features

- Modern React single-page portfolio
- Responsive hero, about, skills, projects, and contact sections
- Light/dark theme toggle with animated transition
- Kinetic background and polished UI interactions
- Project cards with preview images, live demo links, and GitHub links
- Resume PDF available from the public assets
- Contact form UI with toast feedback

## Tech Stack

- React 19
- Vite 7
- Tailwind CSS 4
- React Router
- Radix UI Toast
- Lucide React icons
- ESLint

## Getting Started

### Prerequisites

Install Node.js and npm before running the project.

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open the local URL shown in your terminal, usually:

```bash
http://localhost:5173
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```
